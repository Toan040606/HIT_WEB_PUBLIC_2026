# Bài tập: Semantic HTML & CSS Grid

## Yêu cầu

Thiết kế giao diện **Website bán hàng** gồm:

- Header
- Navigation
- Sidebar
- Main
- Footer

---

## Yêu cầu kỹ thuật

- Sử dụng **HTML Semantic**:
  `header`, `nav`, `main`, `aside`, `section`, `article`, `footer`.
- Sử dụng **CSS Grid** để xây dựng layout.
- Sử dụng **Flexbox** để căn chỉnh thành phần.
- Sử dụng **Font Awesome** cho icon.
- Sử dụng **CSS Variables** với `:root`.
- Menu đa cấp hiển thị bằng `:hover`.
- Card có:
  - Nền trắng
  - Bo góc
  - Đổ bóng
- Sử dụng `:hover` + `transition` tạo hiệu ứng.
