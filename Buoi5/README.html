Phần 01

Tổng quan về CSS Grid

CSS Grid là một hệ thống layout mạnh mẽ để xây dựng bố cục theo hàng và cột.

Grid giúp kiểm soát chính xác vị trí các phần tử con, tạo layout phức tạp và linh hoạt hơn so với Flexbox khi làm việc với hai chiều.

CSS Grid bao gồm các khái niệm cơ bản sau:

  • Grid Container: phần tử cha bật display: grid.
  • Grid Item: phần tử con trực tiếp nằm trong Grid Container.
  • Grid Row & Grid Column: hàng và cột được định nghĩa bằng grid-template-rows và grid-template-columns.
  • Grid Line: đường phân chia các hàng và cột của grid.
  • Grid Track: vùng giữa hai Grid Line.
  • Grid Cell: một ô đơn trong lưới.
  • Grid Area: vùng gồm nhiều Grid Cell.
  • Grid Gap: khoảng cách giữa các hàng và cột.
Phần 02

Cách sử dụng CSS Grid

Bắt đầu bằng cách bật Grid cho một phần tử và định nghĩa số hàng, số cột, khoảng cách, cùng vị trí của các phần tử con.

1. Khai báo một Grid Container

CSS
.container {
  display: grid;
}

2. Định nghĩa số hàng và cột

CSS
.container {
  display: grid;
  grid-template-columns: 100px 200px 100px;
  grid-template-rows: 150px 150px;
}

Hoặc sử dụng đơn vị fr để chia không gian còn lại:

CSS
.container {
  display: grid;
  grid-template-columns: 1fr 2fr 1fr;
}

Hàm repeat() giúp rút gọn khi có các cột hoặc hàng lặp lại:

CSS
.container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

3. Khoảng cách giữa hàng và cột

CSS
.container {
  display: grid;
  grid-gap: 20px;
}
CSS
.container {
  display: grid;
  grid-row-gap: 10px;
  grid-column-gap: 15px;
}

4. Định vị Grid Item

CSS
.item {
  grid-column: 1 / 3;
}
CSS
.item {
  grid-row: 2 / 4;
}
CSS
.item {
  grid-area: 1 / 1 / 3 / 4;
}
CSS
.item {
  grid-column: span 2;
  grid-row: span 3;
}

5. Grid Area đặt tên

CSS
.container {
  display: grid;
  grid-template-areas:
    "header header header"
    "main main sidebar"
    "footer footer footer";
}

.header { grid-area: header; }
.main { grid-area: main; }
.sidebar { grid-area: sidebar; }
.footer { grid-area: footer; }

Ngoài ra, có thể sử dụng align-items, justify-items, align-content, justify-content, align-self, justify-self để căn chỉnh nội dung trong grid.

Phần 03

CSS Position

CSS Position dùng để định vị phần tử và kiểm soát cách nó xuất hiện trên trang.

Position giúp tạo các lớp layout khác nhau: giữ vị trí trong luồng, di chuyển liên quan đến phần tử cha, cố định với viewport, hoặc dính khi cuộn.

1. static

Giá trị mặc định. Phần tử sắp xếp theo luồng tài liệu và không phản hồi với top, left, right, bottom.

CSS
.static-box {
  position: static;
  background-color: lightblue;
}

2. relative

Phần tử định vị so với vị trí ban đầu của chính nó. Di chuyển mà không làm thay đổi không gian mà nó chiếm trong luồng.

CSS
.relative-box {
  position: relative;
  top: 20px;
  left: 30px;
  background-color: lightgreen;
}

3. absolute

Phần tử định vị so với phần tử cha gần nhất có position khác static. Nó rời khỏi luồng tài liệu.

HTML
<div class="relative-container">
  <div class="absolute-box">Box</div>
</div>
CSS
.relative-container {
  position: relative;
  width: 300px;
  height: 200px;
  background-color: lightgray;
}

.absolute-box {
  position: absolute;
  top: 10px;
  left: 20px;
  background-color: lightpink;
  padding: 10px;
}

4. fixed

Phần tử định vị so với cửa sổ trình duyệt. Vị trí không thay đổi khi cuộn trang.

CSS
.fixed-box {
  position: fixed;
  top: 10px;
  right: 10px;
  background-color: yellow;
  padding: 10px;
}

5. sticky

Phần tử như relative cho đến khi cuộn đến vị trí cố định, sau đó hoạt động giống fixed trong phạm vi container của nó.

HTML
<div class="sticky-container">
  <div class="sticky-box">Sticky Box</div>
</div>
CSS
.sticky-container {
  height: 200vh;
}

.sticky-box {
  position: sticky;
  top: 20px;
  background-color: orange;
  padding: 10px;
}

6. Ví dụ kết hợp relative + absolute

HTML
<div class="relative-container">
  <div class="absolute-child">Absolute Child</div>
</div>
CSS
.relative-container {
  position: relative;
  width: 400px;
  height: 300px;
  background-color: lightblue;
}

.absolute-child {
  position: absolute;
  top: 50px;
  left: 100px;
  background-color: lightcoral;
  padding: 10px;
}

CSS Position cho phép tạo các layout đặc biệt, cố định và các phần tử nổi mà không phá vỡ cấu trúc chính của trang.

Phần 04

CSS Animation

CSS Animation giúp tạo hiệu ứng chuyển động mượt mà giữa nhiều trạng thái của phần tử.

1. Khai báo @keyframes

@keyframes định nghĩa trạng thái bắt đầu và kết thúc, hoặc nhiều điểm trung gian bằng phần trăm.

CSS
@keyframes moveRight {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(200px);
  }
}
CSS
@keyframes bounce {
  0%,
  100% {
    transform: translateY(0);
  }
  50% {
    transform: translateY(-50px);
  }
}

2. Thuộc tính animation

animation-name: tên @keyframes.

animation-duration: thời gian hoạt ảnh.

animation-timing-function: cách thay đổi tốc độ.

animation-delay: trì hoãn trước khi bắt đầu.

animation-iteration-count: số lần lặp.

animation-direction: hướng chạy.

CSS
.animation-box {
  animation: bounce 2s ease-in-out 1s infinite alternate;
}

3. Ví dụ cụ thể

CSS
@keyframes moveRight {
  from {
    transform: translateX(0);
  }
  to {
    transform: translateX(200px);
  }
}

.box {
  width: 100px;
  height: 100px;
  background-color: lightblue;
  animation: moveRight 2s ease-in-out infinite;
}
Phần 05

CSS Transition

CSS Transition tạo hiệu ứng mượt khi thuộc tính CSS thay đổi, thường dùng cho hover, focus hoặc trạng thái active.

1. Thuộc tính transition

CSS
transition-property: background-color;
transition-duration: 0.3s;
transition-timing-function: ease-in-out;
transition-delay: 0.2s;

2. Cú pháp shorthand

CSS
transition: background-color 0.3s ease-in-out 0.2s;

3. Ví dụ cụ thể

CSS
.transition-box {
  width: 200px;
  height: 200px;
  background-color: lightblue;
  transition: background-color 0.5s ease;
}

.transition-box:hover {
  background-color: lightgreen;
}

4. Một số thuộc tính thường dùng

  • transform: translate, scale, rotate.
  • color, background-color, opacity.
  • box-shadow, filter.
CSS
.scale-button {
  transition: transform 0.2s ease-out;
}
.scale-button:hover {
  transform: scale(1.1);
}
